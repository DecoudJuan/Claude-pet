Mascota SVG · sin API de imágenes

Un pingüino que te sigue con la mirada.

Un busto: anteojos de aro negro fino, auriculares de vincha, pico naranja a dos tonos, todo plano y con línea negra. Dibujado a mano en SVG — no generado — así que no necesita ninguna clave de API para existir. Mové el cursor y gira la cabeza. Tocalo y pega un salto.

→ tocá al pingüino

Un dibujo, varias tintas

Tres paletas, el mismo pingüino.

El SVG no tiene ni un color escrito adentro: todo sale de seis variables CSS. Cambiar de paleta es cambiar un atributo, no redibujar nada.

Ponerlo en tu página

Un div, un script, una línea.

<div id="mascota"></div>

<script src="penguin-mascot.js"></script>
<script>
  PenguinMascot.mount(document.getElementById('mascota'), {
    palette: 'riso'
  });
</script>
// o dejá que se monten solos, por atributo
<div data-penguin-mascot data-palette="menta"></div>
PenguinMascot.mountAll();
palette
colour, riso o menta. O definí las tuyas sobrescribiendo --pm-ink, --pm-frame, --pm-snow, --pm-beak, --pm-beak-shade y --pm-silver.
label
El aria-label del dibujo. Ya viene con uno en castellano.
interactive
false lo deja mirando pero sin foco de teclado ni reacción al toque.
.poke()
Dispara el salto desde tu propio código — cuando se envía un formulario, por ejemplo.
.setPalette()
Cambia la tinta en caliente, sin desmontar.
.destroy()
Corta el requestAnimationFrame, los timers y los listeners. Para SPAs.

Detalles

Lo que hace mientras no lo mirás.

deriva
Si el cursor no se mueve por 2,6 segundos deja de seguirlo y mira despacio alrededor, en dos senos desfasados para que no se note el ciclo.
parpadeo
Cada 2,2 a 6,4 segundos, y una de cada cinco veces parpadea dos veces seguidas. Se frena con la pestaña en segundo plano.
paralaje
Las pupilas se mueven más que la cabeza y la cabeza más que el cuerpo. Es lo único que hace que parezca que mira, y no que rota.
accesibilidad
Enfocable con Tab, se toca con Enter o barra espaciadora, y con prefers-reduced-motion conserva la mirada pero se queda quieto.
